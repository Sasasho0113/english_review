# Security Policy

## About This Project

This repository contains static HTML/CSS/JavaScript files for a school English learning site ("Shota's English Review Room") used at a Japanese junior high school.  
There are no server-side components, databases, or user authentication systems.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

This project does not use version numbers. Only the latest files in the `main` branch are maintained.

## Reporting a Vulnerability

If you discover a security issue (e.g., a malicious external link, exposed personal information, or unsafe embedded content), please report it by either:

- **Email:** r162@yachiyo.ed.jp
- **GitHub Issues:** Open an issue in this repository

We will review all reports and respond within a few business days.  
Since this is a small school project maintained by a single teacher, we appreciate your patience.

## Scope

- ✅ Broken or malicious external links
- ✅ Accidental exposure of student personal information
- ✅ Unsafe embedded content (iframes, scripts)
- ❌ Issues unrelated to this repository
- ❌ Vulnerabilities in third-party services (Google Drive, Kahoot!, Gemini, etc.)
