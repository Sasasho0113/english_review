# 📚 Shota's English Review Room

> 高津中学校 英語科 生徒向け学習サイト

**授業スライド・配布プリント・学習アプリ・解説動画**をまとめた、英語授業の復習用Webサイトです。  
生徒がいつでも・どの端末からでもアクセスして復習できることを目的としています。

🔗 **公開URL：** https://sasasho0113.github.io/english_review/
